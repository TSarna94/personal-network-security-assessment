# Personal Network Security Assessment

## Overview

This project documents a security assessment I performed against a local network using Nmap and Nessus. The assessment focused on network discovery, service enumeration, and vulnerability scanning to identify potential security risks and evaluate the overall security posture of the environment.

## Objectives

- Identify active devices on the local network
- Perform service and port enumeration
- Conduct vulnerability scanning
- Analyze security findings
- Document assessment results and recommendations

## Tools Used

- Kali Linux
- Nmap
- Nessus

## Methodology

### Stage 1 - Network Discovery and Enumeration

Nmap was used to identify active hosts and enumerate network services.

Activities included:

- Host discovery
- Port scanning
- Service enumeration
- Network topology identification

### Key Findings

- One active host was identified on the local network
- Firewall protections prevented detailed port enumeration
- No exposed services were identified during the scan
- Host filtering indicated active endpoint protection

### Stage 2 - Vulnerability Assessment

Nessus was used to perform a local vulnerability assessment against the identified host.

Activities included:

- Vulnerability scanning
- Security configuration review
- Risk assessment
- Security findings analysis

### Results

The assessment identified:

- 0 Critical vulnerabilities
- 0 High vulnerabilities
- 0 Medium vulnerabilities
- 0 Low vulnerabilities
- 5 Informational findings

The results indicated that no significant vulnerabilities were identified during the assessment and that existing security controls were functioning as expected.
